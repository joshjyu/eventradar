How it works

A scheduled job reads structured, public event data: Luma and community calendars (iCalendar), Meetup's and Devpost's APIs, and schema.org markup on event pages. It never scrapes page layouts, and it honors every site's robots.txt.

Events are geocoded, deduplicated across platforms, filtered to Southern California's eight counties and to tech topics, and published as static JSON, iCalendar, and RSS. A Cloudflare Worker starts the run each morning; sources that break are detected and reported automatically.
